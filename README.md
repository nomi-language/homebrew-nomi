# homebrew-nomi

The Homebrew tap for [Nomi](https://nomi-lang.org).

```sh
brew install nomi-language/nomi/nomi
```

`Formula/nomi.rb` is rendered for each release by `scripts/homebrew-formula.sh`
in [nomi-language/nomi](https://github.com/nomi-language/nomi) from the
release's checksums. Do not edit it here.
